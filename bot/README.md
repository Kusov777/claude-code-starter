# Бот Telegram Prorabchik

Бот выполняет команды PowerShell, полученные из Telegram, и отправляет результаты обратно.

## 🚀 Быстрый старт (автоматический)

### Шаг 1: Запустите скрипт настройки

Просто запустите файл `run.bat` двойным кликом или командой:

```bash
cd bot
run.bat
```

Скрипт автоматически:
- ✅ Проверит конфигурацию
- ✅ Получит ваш ID пользователя
- ✅ Установит зависимости
- ✅ Запустит бота

### Шаг 2: Настройте бота в Telegram

1. **Получите токен бота:**
   - Напишите `@BotFather` в Telegram
   - Отправьте `/newbot`
   - Дайте имя: `Prorabchik`
   - Дайте юзернейм: `@ProrabchikBot` (или любой уникальный)
   - Скопируйте токен

2. **Добавьте токен в `.env`:**
   ```bash
   TELEGRAM_TOKEN=ваш_токен_здесь
   ```

### Шаг 3: Получите ваш ID

Скрипт `run.bat` автоматически запустит получение ID:
- Напишите любое сообщение боту в Telegram
- Бот покажет ваш ID
- Скопируйте ID в файл `.env`

## 📱 Использование

Отправьте любую команду PowerShell боту, например:

- `/start` - приветствие
- `/help` - справка
- `dir` - список файлов
- `Get-Process` - процессы
- `python --version` - версия Python
- `git status` - статус репо

## 🔧 Ручная настройка (если автоматическая не сработала)

### 1. Создайте .env файл

```bash
copy .env.example .env
```

Отредактируйте `.env`:

```
TELEGRAM_TOKEN=ваш_токен_от_BotFather
ALLOWED_USER_ID=ваш_id_от_userinfobot
COMMAND_TIMEOUT=30
```

### 2. Получите ID пользователя

```bash
python get_user_id.py
```

Напишите боту в Telegram - он покажет ваш ID.

### 3. Запустите бота

```bash
python bot.py
```

## 🚨 Проблемы?

### "TELEGRAM_TOKEN not set"
→ Добавьте токен в `.env`

### "ALLOWED_USER_ID is 0"
→ Запустите `python get_user_id.py`

### "ModuleNotFoundError"
→ `pip install -r requirements.txt`

### Бот не отвечает
→ Проверьте интернет и токен
